## Summary

Registers the **`firecracker` word** in this provider — the step between the landed contract (`opencharly/spec#227` added `kind: firecracker`, `#SubstrateKind: firecracker` and the `target` member) and the substrate plugin itself (WI-5). Closes #28; umbrella ledger WI-4.

The contract can **name** a kind; only a provider can **serve** it. Without this, a `kind: firecracker` node would have no provider declaring the word, no template-resolve arm, and no status row — `charly status` would silently drop a microVM deploy from its fan-out.

**The trait row, and why the absence in it is the point:**

```
"firecracker": {Venue: "ssh", ImageBacked: true, BedTarget: true, SupportsEphemeral: true}
```

- **`Venue: "ssh"`** — a microVM is reached over SSH, and the contract's venue enum has no `firecracker` member, so `ssh` says exactly what is true without a second contract change.
- **NO `ExclusiveVenue`** — the load-bearing part. `IsVmVenue` is `ssh ∧ exclusive_venue`, so claiming an exclusive venue would make the kernel **misroute** the deploy into `charly vm build`/`charly vm create` — the bug `fe624e5` fixed for kubevirt, whose row carries the ssh venue without it for the same reason. A microVM holds no host-global domain and no arbiter lease, so it must not claim one.
- **`ImageBacked`** — the box *is* an OCI image carrying the rootfs and kernel artefacts (WI-2/WI-3). **`BedTarget`** — a disposable bed boots a real microVM (WI-13). **`SupportsEphemeral`** — a microVM is create/destroy-able per run, which is what the ephemeral TTL seam expects.

**The resolve arm carries the raw body and invents nothing.** A `kind: firecracker` template describes the *host's* capabilities and the microVM shape; it names no hostname, because the host is the **deploy's** own venue (its `host:`), exactly as local and vm deploys carry theirs. So `ResolvedFirecracker.Host` is left for whoever resolves the venue, and a test asserts this leg does not fabricate one.

**Pins.** `spec` → the contract carrying the kind; `sdk` → **`v0.2026287.1311`**, the tag carrying *both* the alias removal this module needs in order to compile against that contract and the microVM emitter (WI-3). Measured: with only the `spec` bump the module fails on `undefined: spec.KubernetesGatewayAPI` (six sites, in the *pinned sdk*), which is why both move together.

`TestSubstrateWordsAllDeclareTraits` is the invariant that keeps a half-registered word from shipping: the kernel reads behaviour **off the traits**, so a word without a row would fall through to "external-in-place" by accident rather than by decision.

**One seam deliberately left to WI-5, stated rather than faked.** The ephemeral TTL seam's reap-orphans liveness probe has a per-word arm; an unknown target returns `true` (conservative — assume alive). A *real* firecracker arm needs the VMM conversation (the lease's API socket and whether the process answers), which is the substrate plugin's own knowledge, and a socket file is not a service (ledger probe P2). So this change does not add an arm that would claim more than a file check can: the reaper stays conservative until WI-5 can probe properly.
