# 2026.269.1716 — feat(vm): require distro: on the container_disk source arm

## Summary

The `container_disk` arm (spec#171, **merged**) pulls a prebuilt guest disk out of an OCI
artifact and boots it through the unchanged libvirt/qemu path. It is **cloud_image-like**: the
disk already exists and charly seeds it through cloud-init, so the SAME guest dispatches apply
— the distro selects the package NAME (`openssh` vs `openssh-server`), the package MANAGER,
and the sshd UNIT name (`sshd` vs `ssh`). Omitting it is the identical
silent-unreachable-guest failure the check was built to catch.

So `container_disk` joins `distroBearingSourceKinds` alongside `cloud_image` and `bootstrap`.
