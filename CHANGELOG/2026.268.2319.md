feat(substrate): add the kubevirt substrate kind

Adds `kubevirt` to candy/plugin-substrate's served substrate words: the kind provider, the traits entry, the template-resolve arm, the status collector, and the reap-orphans probe. Companion to opencharly/spec#161 (**merged**, tag **`v0.2026268.2214`**) + opencharly/sdk#289 (**merged**, tag **`v0.2026268.2244`**).

This PR carries the pin bumps to those merged tags (`spec v0.2026268.2214`, `sdk v0.2026268.2244`), so the committed tree builds green at the shipped pins with `GOWORK=off` (no dev overlay).

## Summary of changes

- **`plugin.go`** — `substrateWords += kubevirt`; traits `{Venue:"ssh", ImageBacked:true, BedTarget:true, SupportsEphemeral:true, SupportsFromSnapshot:true}` (NO `ExclusiveVenue` — a cluster-scheduled VM holds no host lease); `Validates` now covers `vm` + `kubevirt`.
- **`validate_kubevirt.go`** (NEW) — deep `OpValidate`: source-arm kind known (TEMPLATE shape only; a `source:` pointer distinguishes it from a `from:`/`image:` deploy), `container_disk` forbids `storage_class`, `gpus[]` resource_name XOR device_name, `instancetype` XOR explicit cpu.
- **`resolve.go`** — the kubevirt substrate-template resolve arm.
- **`status_kubevirt.go`** (NEW) — the `OpStatus` collector + the pure `buildKubevirtRows` it delegates to.
- **`status_collect.go`** / **`status_flat.go`** — the kubevirt dispatch + fan-out + `enrichKubevirtRow`.
- **`command_reap_orphans.go`** — a conservative `kubectl get vm` liveness probe (no kubectl → assume alive).
- **`charly.yml`** — `kind:kubevirt` provider + the word-list sweep.
- **`go.mod`/`go.sum`** — the spec + sdk pin bumps.
- **Tests** — `validate_kubevirt_test.go`, `resolve_test.go` (+`TestResolveKubeVirt_FieldCopy`), `status_kubevirt_test.go` (+`TestBuildKubevirtRows`).
