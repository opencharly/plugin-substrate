# 2026.266.1412 — refactor(status): migrate the guest-probe cache to the spec/cache ArtifactStore

## Summary

Migrates `plugin-substrate`'s guest-probe cache onto the new `spec/cache` **ArtifactStore** (spec#148), which replaced the keyed `Store` with a content-addressed OCI Image Layout.

The merged engine cutover (#14, merged 2026-09-23) pinned `spec v0.2026266.545` — which still carried the old `cache.Store`. spec#148 deleted `cache.Store`/`OpenNamed`/`ReadTTL`/`WriteValue`, so **the merged plugin-substrate no longer builds against the new spec** — a cross-repo break surfaced while building a live charly carrying the merged engine-class plugins (opencharly/charly#632's fan-out). This PR is the substrate consumer leg of that fan-out.

- `probeCacheStore()` → `*cache.Layout` via `cache.OpenNamedLayout("probes")`.
- read: `Get` + `FreshTTL(probeCacheTTL)` + `Decode`; write: `Put(key, cache.Entry{Payload: json.Marshal(results)})`.
- same key, same 30s TTL, same live-up/down-never-cached contract.
- `go.mod`: `spec` → `v0.2026266.1306`, `sdk` → `v0.2026266.1111`.

**Files (5):** `candy/plugin-substrate/status_probes.go`, `candy/plugin-substrate/probe_cache_store_test.go`, `candy/plugin-substrate/probe_cache_live_test.go`, `candy/plugin-substrate/go.mod`, `candy/plugin-substrate/go.sum`.
