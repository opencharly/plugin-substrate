# 2026.318.1610 — feat(vm): own the kind body, and bring the contract pins current

## Summary

`opencharly/spec#304` unit 8 (`vm`), the **plugin leg**: `plugin-substrate` takes the `vm` body, and — because the leg's own measurement exposed it — this repo's contract pins come up to date.

**The body.** Seven defs move into the kind-serving plugin's CUE module: `#Vm` itself, `#VmBackend`, `#VmBackendName`, `#VmChecksum`, `#VmInstaller`, `#VmKeyInjection`, `#VmCharlyInstall`, plus the `#VmValue` twin and the `InputDef` declaration. `#Vm` cites the **keepers** the resolve envelope pins in the contract (`schema.#VmSource`, `schema.#VmNetwork`, `schema.#VmSsh`, `schema.#VmCloudInit`, `schema.#VmKrun`, `schema.#VmSnapshot`, `schema.#LibvirtDomain`) and the **eight public vocabulary re-exports** `opencharly/spec#320` added (`schema.#VmBackendNameWord` … `schema.#VmKindWord`), because a plugin cannot reference a private `_<x>Word` and the private tables are shared with the keepers.

**The RCA, and why the pins are in this PR.** The leg first failed its own gate: 32 `vm` bodies moved from OK to FAIL with `#VmValue.source: field not allowed`. The chain of measurement:

1. the composed `#Vm` came back with **four** fields; the authored def and the base's are byte-identical after normalising the `schema.#…` prefixes;
2. **every def the new file added came back EMPTY** from `schemacompose.ServedText` (`#VmCharlyInstall` 0 fields, `#VmChecksum` 0, `#VmValue` 0), while the served text carried them intact at line 1134 of 64,071 bytes;
3. **root cause**: this repo pinned `spec v0.2026317.51`, which predates `opencharly/spec#320` — and `schemacompose` serves the spec module at the PLUGIN'S pinned version, so every `schema.#Vm<X>Word` reference was unresolvable. A green suite had been hiding it: this repo was judging an older contract than the org's.

The bump (`spec v0.2026318.1519`, `sdk v0.2026318.602`) is the fix, and it exposed four stale references in this repo's own tests — `spec.Kindcluster` (unit 5), `spec.KubeVirt` (unit 6, the capital-V case a case-folded grep misses), `spec.Pod` (unit 3) — each used only to marshal a body the resolve arms consume as **opaque bytes**. Each site now feeds the wire JSON directly.
