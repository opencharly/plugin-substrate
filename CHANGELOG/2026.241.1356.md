# 2026.241.1356 — perf(status): cache the guest tool-probe results

## Summary

The guest probes (`podman exec` per container, spawning conmon/crun) were the remaining cost of `charly status` with multiple containers. The probe results are the container's TOOL availability (metadata — the tools change only on an image rebuild), so they are cached with a 30s TTL; the LIVE up/down status (`podman ps`) is never cached. The probe script (the concatenated snippets) is the cache key — a change to any probe invalidates the cache. Measured: `charly status` 0.63s → 0.50s warm with 3 containers.
